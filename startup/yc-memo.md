# YC Memo

## Company

Apply via Agent is building a managed intake and translation network for job applications. We help employers accept declared, structured, agent-submitted applications and translate reusable applicant data into employer-specific hiring schemas instead of forcing candidate agents through human web forms.

## Problem

Candidate-side AI job applications already exist, but they currently impersonate humans inside brittle application flows. Employers get noisy payloads, duplicates, weak provenance, and rapidly declining trust in inbound applicants, while candidates keep re-entering the same information into incompatible application forms.

## Solution

We provide an employer-side managed intake gateway that exposes `Apply via Agent` on jobs, translates canonical applicant profiles into employer-specific schemas, verifies consent and provenance, runs dedupe and trust checks, and syncs accepted applications into the employer's ATS.

## Why Now

The category is opening because all three layers are moving at once:

- candidate automation is already real
- recruiter-side AI is entering mainstream workflows
- employers are explicitly reacting to fraud, spam, and low-trust inbound data

## Why We Win

We are not building another auto-apply bot. We are building the managed intake layer employers buy first and the reusable applicant network that compounds over time. Every new employer schema improves our translation layer, and every new applicant profile improves reuse, dedupe, and trust across the network.
